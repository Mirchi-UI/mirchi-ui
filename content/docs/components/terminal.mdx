## Features

- **Sequential Animations**: Items appear one after another, perfect for simulating real terminal output.
- **Typing Effect**: `TypingAnimation` subcomponent for realistic command entry.
- **Reveal Effect**: `AnimatedSpan` for instant but smooth appearance of output lines.
- **MacOS Style**: Authentic window controls and styling.
- **Motion Powered**: Built with `motion/react` for buttery smooth transitions.

---

## Usage

```tsx
import { 
  Terminal, 
  AnimatedSpan, 
  TypingAnimation 
} from "@/components/modules/terminal/Terminal";

export function TerminalDemo() {
  return (
    <Terminal>
      <TypingAnimation>&gt; pnpm install</TypingAnimation>
      
      <AnimatedSpan className="text-green-500">
        ✔ Dependencies installed successfully.
      </AnimatedSpan>
      
      <TypingAnimation className="text-muted-foreground">
        Ready to start development.
      </TypingAnimation>
    </Terminal>
  );
}
```

## Props

### Terminal

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | - | The content of the terminal. |
| `className` | `string` | - | Custom styling for the terminal container. |
| `sequence` | `boolean` | `true` | Whether to animate children sequentially. |
| `startOnView` | `boolean` | `true` | Start animations only when the terminal is in view. |

### TypingAnimation

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `string` | - | The text to type out. |
| `duration` | `number` | `60` | Speed of typing in ms per character. |
| `delay` | `number` | `0` | Delay before starting the animation. |
| `as` | `string` | `"span"` | The HTML element to render as. |

### AnimatedSpan

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | - | Content to reveal. |
| `delay` | `number` | `0` | Delay before revealing. |
| `className` | `string` | - | Custom styling. |
