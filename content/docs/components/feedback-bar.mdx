## Props
| Prop           | Type              | Default               | Description                                      |
| -------------- | ----------------- | --------------------- | ------------------------------------------------ |
| `title`        | `string`          | `"Was this helpful?"` | Text displayed in the feedback bar               |
| `icon`         | `React.ReactNode` | `undefined`           | Optional icon displayed before the title         |
| `onHelpful`    | `() => void`      | `undefined`           | Callback when user clicks the helpful button     |
| `onNotHelpful` | `() => void`      | `undefined`           | Callback when user clicks the not helpful button |
| `onClose`      | `() => void`      | `undefined`           | Callback when the close button is clicked        |
| `className`    | `string`          | `undefined`           | Additional classes for styling                   |
