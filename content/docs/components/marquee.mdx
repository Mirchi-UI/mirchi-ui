## Props


| Prop            | Type                                  | Default   | Description |
|-----------------|---------------------------------------|----------|-------------|
| `children`      | `React.ReactNode`                     | —        | Content to be displayed and scrolled inside the marquee |
| `direction`     | `"left" \| "right" \| "up" \| "down"` | `"left"` | Controls the scrolling direction |
| `speed`         | `number`                              | `25`     | Duration of the animation in seconds (lower = faster) |
| `repeat`        | `number`                              | `3`      | Number of duplicated content groups for seamless looping |
| `hoverBehavior` | `"pause" \| "slow" \| "none"`         | `"pause"`| Defines how animation behaves on hover |
| `fade`          | `boolean`                             | `true`   | Enables gradient fade effect on edges |
| `className`     | `string`                              | —        | Additional custom styles for the wrapper |
| `...props`      | `HTMLDivElement props`                | —        | All native `div` attributes (e.g., `id`, `style`, `onClick`) |
