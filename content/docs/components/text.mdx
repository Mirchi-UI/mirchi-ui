## Blurred Split

A text effect that splits letters and reveals them with a smooth blur fade-in animation as it enters the view.

    <SplittingText
      text="Delightful Interactions"
      variant="blur"
      inView={true}
      delay={100}
    />
  </div>
</Preview>

```tsx
import SplittingText from "@/components/modules/texts/SplittingText";

export function Demo() {
  return (
    <div className="text-4xl font-bold">
      <SplittingText
        text="Delightful Interactions"
        variant="blur"
        inView={true}
        delay={100}
      />
    </div>

}
```

## Typewriter Effect

A classic typewriter effect that types out characters sequentially, complete with a blinking cursor.

<Preview link="texts/TypewriterText.tsx" comment={["motion", "typewriter", "interval"]}>
  <TypewriterText speed={50} showCursor={true} />
</Preview>

```tsx
import TypewriterText from "@/components/modules/texts/TypewriterText";

export function Demo() {
  return (
    <TypewriterText 
      text="The game is afoot, and every clue whispers a hidden truth..." 
      speed={50} 
      showCursor={true} 
    />
  );
}
```
